# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone, regardless of age, background,
ability, gender identity, experience level, nationality, appearance, religion or language. The project
serves Arabic- and English-speaking users, and contributions in either language are welcome.

## Expected behaviour
- Be respectful, patient and constructive; assume good intent.
- Give and accept feedback gracefully - critique code and ideas, never people.
- Keep discussions on topic and help newcomers get unstuck.

## Unacceptable behaviour
- Harassment, insults, discriminatory jokes or personal attacks.
- Sexualised language or unwelcome attention.
- Publishing others' private information (including real personal data in test datasets).
- Sustained disruption of discussions or any conduct that would be inappropriate in a professional setting.

## Enforcement
Maintainers may edit or remove comments, commits and issues that violate this code, and may temporarily
or permanently ban contributors for repeated or serious violations. Report concerns privately through
GitHub's "Report content" feature or by contacting a maintainer; reports are handled confidentially.

This Code of Conduct is inspired by the Contributor Covenant (https://www.contributor-covenant.org).
